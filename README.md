# AI Mock Interview Platform

An AI-powered MERN Stack application that helps users prepare for technical interviews by generating AI-based interview questions from their resumes and providing intelligent feedback.

## Features

- 🔐 Google Authentication (Firebase)
- 📄 Resume Upload (PDF)
- 🤖 AI Resume Analysis
- 💬 AI-Generated Technical & HR Interview Questions
- 📊 AI Feedback & Interview Reports
- 💳 Credit-Based Access System
- 💸 Razorpay Payment Integration
- 🎨 Responsive UI with Framer Motion

## Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
- Firebase Authentication
- Razorpay
- Framer Motion
- Tailwind CSS
